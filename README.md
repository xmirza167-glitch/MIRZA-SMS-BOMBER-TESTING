# LemonLeek SMS Lab — GitHub Pages edition

Yeh static, single-page website hai. Is mein Node.js ya backend ki zaroorat nahi.

## GitHub Pages par publish karna
1. Is ZIP ko extract karein.
2. GitHub par nayi repository banayein.
3. `index.html` aur `README.md` ko repository ke root mein upload karein.
4. Repository mein **Settings → Pages** kholein.
5. **Deploy from a branch** select karein.
6. Branch `main`, folder `/(root)` select karke **Save** dabayein.
7. Kuch minute baad GitHub Pages ka URL Settings → Pages mein nazar aa jayega.

## Features
- Responsive dashboard
- Pakistani phone number format validation
- 5, 10, 15, 25, 50, 100 demo OTP choices
- Browser-only generated codes
- Copy results and session activity log
- No server and no third-party dependencies

**Important:** Website codes ko sirf page par simulate karti hai. Yeh real SMS/OTP send nahi karti. Session history refresh par clear ho jati hai.
